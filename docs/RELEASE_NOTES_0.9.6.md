# 西新世紀末物語 — Version 0.9.6 PWA Release Notes

更新日：2026-07-31

Version 0.9.6は、正式GitHub Pages URLをそのままアプリとして端末へ追加できるPWA版です。ゲームデータを初回に一括ダウンロードして端末に保存し、以降はオフラインでも遊べます。実行正本はIssue #114、前提となるVersion 0.9.5.2 Hotfixの正本はIssue #113です。

正式URL：https://susano-ooo.github.io/Zombieee/

## 遊びはじめかた

1. 正式URLを開きます。
2. 初回のゲームデータをダウンロードします（531ファイル・約111MB、Wi-Fi推奨）。
3. iPhoneはSafariの「ホーム画面に追加」、AndroidはChromeの「アプリをインストール」を実行します。
4. 以降はホーム画面のアイコンから起動します。

証明書のインストール、専用アプリストア、PCの起動はいずれも不要です。ブラウザのタブで開いた場合はこれまでどおりそのまま遊べます。ダウンロード画面が出るのはホーム画面から起動したときだけです。

## 追加

- **PWA化**：Web App Manifest、ホーム画面アイコン、standalone表示、landscape固定に対応しました。Service Workerは正式な`/Zombieee/` scopeで登録されます。
- **初回一括ダウンロード**：背景、Stage、unit、敵、boss、portrait、BGM、SE、voiceを1回でまとめて端末へ保存します。件数、概算MB、空き容量の目安、取得中の分類、進捗、失敗件数を表示します。
- **一時停止・再開・中断・再試行**：中断しても検証済みのデータは保持し、次回は続きから再開します。失敗したassetだけを同じ画面で再試行でき、タイトルへは戻りません。全画面reloadを復旧手段として使いません。
- **保存前の検証**：size一致とsha256一致の両方を満たしたassetだけを保存します。検証に通らないデータは保存しません。
- **オフライン起動**：ダウンロード済みの範囲で、タイトル→マップ→編成→戦闘→リザルトまでオフラインで進行できます。
- **差分アップデート**：新Versionはタイトルまたはマップで通知します。更新Version、変更概要、必要ダウンロード量を表示し、**追加・変更されたassetだけ**を取得します。内容が変わっていないassetは再ダウンロードしません。
- **安全な切り替え**：更新の適用は安全な画面でのみ行います。戦闘中、リザルト保存中、セーブ書き込み中、ダウンロード中には切り替えません。
- **ロールバック世代の保持**：新Versionを検証して有効化するまで旧Versionのデータを削除せず、1世代を保持します。更新に失敗しても旧Versionで起動できます。
- **データ管理**：保存済み件数、現在のVersion、release SHA、不足・破損件数を確認でき、assetだけを削除できます。

## Save互換

save schemaはv14のままです。PWA内で作成したsaveは、以降のアップデートを跨いで保持されます。saveとasset cacheは分離されており、assetの削除・更新・再取得はsaveに影響しません。

Version 0.9.6では、既存のSafari／Chromeブラウザ版saveをPWAへ移行する機能は提供しません。PWAは新規スタートになります。ブラウザのタブで開けば、従来のsaveはこれまでどおり利用できます。

## 非対象

App Store／Google Play対応、Capacitorなどのネイティブ包装、新Stage、新unit、boss強化は含みません。既存の`v0.9.5`／`v0.9.5.1` tagとReleaseは変更しません。Version 0.9.5.2は単独公開せず、本Versionに統合して公開します。

## 既知の制約

- 端末のOSがストレージを回収した場合、不足分だけを再取得します。全件の再ダウンロードにはなりません。
- 初回ダウンロードは約111MBです。モバイル回線での実行前に通信量にご注意ください。
