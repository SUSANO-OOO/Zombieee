# 西新世紀末物語 — Version 0.9.6.2 Hotfix Release Notes

更新日：2026-07-31

Version 0.9.6.2は、Version 0.9.6.1の公開後QAが検出した1件の不具合だけを修正する緊急Hotfixです。実行正本はIssue #114、関連はIssue #113です。PWAの機能内容はVersion 0.9.6から変わりません。

正式URL：https://susano-ooo.github.io/Zombieee/

## 修正

**編成画面で「アセット準備中」のまま出撃できなくなる問題を修正しました。**

地図でステージを選び直してから編成画面に入ると、必要なアセットがすべて読み込み済み（26/26・「準備完了」表示）であるにもかかわらず、出撃ボタンが「アセット準備中」のまま押せなくなることがありました。この状態では再試行ボタンも表示されないため、**編成画面から先へ進む手段がありませんでした**。

原因は、ステージ選択の処理が準備完了フラグを直接falseへ戻していたことです。アセット準備は、その処理自身が開始時にフラグを下ろし、成功時に立て直す仕組みになっています。ところが準備処理は選択中ステージIDそのものではなく、実際に使うアセットの組み合わせを見て動くため、**同じアセットになるステージを選び直した場合は準備処理が再実行されず、下ろされたフラグを誰も戻しませんでした**。

ステージ選択がこのフラグに触れないようにし、アセット準備処理だけが管理するようにしました。

Version 0.9.5.2で導入した保証は変わりません。準備は必ず終了し、進捗と失敗件数を表示し、失敗した項目だけをその画面で再試行でき、タイトルへは戻りません。
