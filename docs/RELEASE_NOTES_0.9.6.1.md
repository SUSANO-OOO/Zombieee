# 西新世紀末物語 — Version 0.9.6.1 Hotfix Release Notes

更新日：2026-07-31

Version 0.9.6.1は、Version 0.9.6の公開後QAが検出した1件の不具合だけを修正する緊急Hotfixです。実行正本はIssue #114、関連はIssue #113です。PWAの機能内容はVersion 0.9.6から変わりません。

正式URL：https://susano-ooo.github.io/Zombieee/

## 修正

**編成画面で出撃ボタンが押せなくなる問題を修正しました。**

正式URLで編成画面に入ると「戦闘アセットの準備に失敗／味方ユニット・応答時間を超過」と表示され、出撃ボタンが押せない状態になることがありました。

原因はアセットの欠落ではありません。配信されているファイルはすべて正常で、サイズもハッシュも一致しています。戦闘に必要なユニット画像11件は合計14.1MBあり、公開サーバーからの実測で28.5秒かかっていたのに対し、準備の待ち時間の上限が12秒に設定されていたため、**正常な回線を「失敗」と判定していました**。

待ち時間の上限を実測に見合う値へ広げました。

- 準備全体の上限：12秒 → 90秒
- 画像1枚あたりの上限：15秒 → 30秒
- 任意アセット（音声など）の上限：6秒 → 20秒

あわせて、準備全体の上限（12秒）が画像1枚の上限（15秒）より短く、**どの画像も自分の上限に到達する前に打ち切られていた**矛盾を解消しました。

Version 0.9.5.2で導入した保証は変わりません。準備は必ず終了し、進捗と失敗件数を表示し、失敗した項目だけをその画面で再試行でき、タイトルへは戻りません。上限が広がっただけで、無制限になったわけではありません。

なお、PWAとしてホーム画面から起動する場合は初回に全データを端末へ保存するため、この問題は発生しません。影響を受けるのはブラウザのタブで遊ぶ場合です。
