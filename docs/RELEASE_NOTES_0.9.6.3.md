# 西新世紀末物語 — Version 0.9.6.3 Hotfix Release Notes

更新日：2026-07-31

Version 0.9.6.3は、Version 0.9.6.2の公開後QAが検出した1件の不具合だけを修正する緊急Hotfixです。実行正本はIssue #114、関連はIssue #113です。PWAの機能内容はVersion 0.9.6から変わりません。

正式URL：https://susano-ooo.github.io/Zombieee/

## 修正

**画像のデコードが遅い・止まる端末で、ダウンロード済みの画像が「取得失敗」扱いになる問題を修正しました。**

画像はダウンロードが完了したあと、ブラウザが表示用に展開（デコード）します。この展開が遅い、あるいは止まってしまう端末で、**すでに手元にある画像が「取得できなかった」ものとして扱われ**、戦闘アセットの準備が失敗していました。

Version 0.9.5.1では、展開が滞った場合は読み込み完了イベントと画像サイズを確認して安全に続行する仕組みが入っていました。Version 0.9.5.2でこの経路が失敗扱いに変更されており、本Hotfixで元の動作に戻しました。

画像サイズがゼロのもの（実際に読み込めていない画像）は、これまでどおり失敗として扱います。安全性は下がりません。

save schemaはv14のままです。Version 0.9.6系で作成したPWA内のsaveはそのまま引き継がれます。
