## 1. 文書の役割

本書は、Version 0.9.0で追加する全プレイアブルユニット共通の手動アビリティ基盤、新規5ユニットの人物・武器・アビリティ、既存11ユニットの手動アビリティ初期仕様を所有する。

参照順：

1. `docs/PRODUCER_DECISIONS_0.9.0.md`
2. 本書
3. Issue #68の最新プロデューサー判断

初期ダメージ、効果量、効果時間、クールダウン秒数は、固定された操作・役割・演出を壊さない範囲でCodexがsimulationと実プレイから調整できる。

## 2. 共通の手動アビリティ操作

### 2.1 基本操作

- Version 0.9.0では、新規5体だけでなく既存11体を含む全16体へ手動アビリティを1つずつ実装する
- 各戦場個体は、同じunit kindであっても独立したアビリティ状態とクールダウンを持つ
- 同じユニットを複数召喚した場合、各個体が同じアビリティをそれぞれ発動できる
- unit kind全体でクールダウンを共有しない
- 代表個体だけにアビリティを限定しない
- アビリティは原則として頭上のready iconを1回タップするだけで発動する
- 発動後に地面や対象をもう一度指定する二段階操作は、0.9.0の基本方式にしない
- 攻撃対象、回復対象、着弾地点はアビリティごとの自動選択規則で決める

### 2.2 頭上ready icon

- アビリティが実際に使用可能になった個体だけ、頭上へready iconを表示する
- クールダウン中はiconを表示しない
- 発動直後にiconを消す
- クールダウンの円形ring、数値timer、暗転したiconを頭上へ常時表示しない
- クールダウンが完了し、発動条件と有効対象がそろった時点でiconを再表示する
- 戦闘不能、死亡処理中、退避中、移動拠点からの出撃途中、強制演出中は表示しない
- iconが出ているのに有効対象がなく、押しても何も起きない状態を作らない
- icon tap時は所有個体を短くoutlineまたはflashし、どの個体が発動したか認識できるようにする

### 2.3 スマートフォンの重なり対策

- visible icon自体は小さく保ち、tap判定は透明領域を含めて十分な大きさを確保する
- icon位置はunitのworld座標だけでなく、実表示sprite boundsと頭位置から算出する
- 複数iconが重なる場合は、screen-spaceで左右・上方向へ交互にずらす
- 同じ位置へ重なった個体は、個体ID順などの決定的な規則で扇状または二列へ展開する
- icon同士、上部HUD、boss HP bar、警告表示、safe areaとの重なりを解消する
- 画面端ではiconを表示領域内へclampする
- iconを一つの共有clusterへまとめず、ready状態の各個体へ個別のbuttonを維持する
- iconと所有個体の対応が分からなくなる場合は、短いpointer、stem、outline等で関係を示す
- 844×390と844×340で、大量出撃時も誤タップ、操作不能、画面外見切れを0件にする

### 2.4 視覚・音響

- ready iconは、他作品の形状・配色・素材を複製せず本作独自の軍事端末／汚染世界UIとして制作する
- abilityごとに固有silhouetteを持たせ、文字だけのiconや同じ絵の色替えで済ませない
- readyになった瞬間は短いpulseを1回だけ使えるが、常時点滅させない
- 発動、命中、終了、再使用可能をanimation、VFX、SEと同期する
- 2倍速でもtapを取りこぼさず、重要animationと危険範囲を認識できる
- 新unitへ既存の別人物voiceを流用しない

## 3. 新規5ユニット

### 3.1 ザキミヤ

人物：

- 40代男性
- 最近子どもが生まれた愛妻家
- 酒好き
- 非常にいじられやすい
- 発言の頭に「おーい」が付くことが多い
- 台詞例の方向性は「おーい、それやばいだろう」「おーい、やめろお前」「おーい、なんだお前」

通常武器・攻撃：

- 武器はウイスキー瓶
- 近距離で瓶を握ったまま殴打する
- 通常攻撃のたびに同じ瓶が完全粉砕して復元する不自然な表現を避ける
- 瓶の打撃音、酒の飛沫、ヒビ等で武器の個性を出す

手動アビリティ：**火酒投擲**

- 予備のウイスキー瓶へ着火して投げる
- 射程内で最も多くの敵を巻き込める密集地点を自動選択する
- 単独の最寄り敵を優先して群体処理を無駄にしない
- 着弾時に範囲damageを与え、一定時間の炎上領域を残す
- 味方を直接targetに選ばない
- 生存味方、味方死体、感染timer、焼却との判定は既存火炎systemへ統合し、意図しない壊滅的誤爆と二重damageを防ぐ

icon motif：火の付いたウイスキー瓶と短い投擲軌道。

### 3.2 TKY

人物：

- 表示名は常に`TKY`
- 本名はタクヤだが、enemy boss `TAKUYA`との混同を避ける
- 30代男性
- 非常に整った容姿
- 終末世界でもおしゃれを欠かさない軽装
- 尖った関西弁

標準武器：**プラズマブレード**

- 片手用の細身な光刃武器
- 通常刃は白に近い高輝度coreとpink〜magentaの外縁発光
- 柄、発振器、音、斬撃軌跡は本作独自designにする
- 他作品の武器形状、効果音、固有演出を直接複製しない

通常攻撃：

- 高速の横薙ぎ、斜め切り上げ、短い突き、連続斬撃
- 近接としてやや長いreachを持つ
- 単体から小集団を素早く処理する
- 宮本武蔵より速度・派手さ・範囲を重視する

手動アビリティ：**光刃解放**

- 表記は必ず`光刃解放`とし、`光陣解放`へ変えない
- TKYが構え、プラズマブレードへenergyを収束させる
- pink〜magentaの刃が大きく伸長・巨大化する
- 前方広範囲を一度の迫力ある薙ぎ払いで攻撃する
- 軽量敵を押し戻し、中型敵を短く怯ませる
- bossにもdamageは入るが、主用途は前方の群体処理
- 発動中に向きが勝手に反転せず、背後や画面外の敵を不自然に巻き込まない
- 2倍速でも刃の収束、巨大化、薙ぎ払い、残光を認識できる

icon motif：magentaの巨大光刃と横一閃のarc。

### 3.3 Mrs.チハ

人物：

- 表示名は`Mrs.チハ`
- 女性、年齢不詳
- 綺麗で知的、動作が非常にスマート
- ババヤガの妻
- 夫婦関係は台詞・人物情報へ反映できるが、同時編成必須の性能にはしない

標準武器：**回転弾倉式グレネードランチャー**

- 移動中はランチャーを背中へ収納し、両手を空ける
- 攻撃時に背中から取り出し、構え、発射し、収納する一連の専用animationを持つ
- 弾道と着弾地点を一致させ、範囲damageを与える
- 最低射程内へ敵が侵入した場合は、ランチャー本体で殴る
- 武器が手へ瞬間移動する仮表現で完成扱いにしない

手動アビリティ：**全弾制圧**

- 回転弾倉の榴弾を連続発射する
- 敵密集地点を複数選び、順番に着弾させる
- 最終弾は範囲と押し戻しを強化する
- 発動中は足を止め、通常攻撃へ途中復帰しない
- 発射、recoil、弾倉回転、着弾、爆発、収納を専用SE・VFXと同期する

icon motif：回転弾倉と複数の爆着点。

### 3.4 宮本武蔵

人物：

- 歴史上の宮本武蔵を名乗る男性
- 顔、記憶、剣技、言動が記録と異常なほど一致する
- 本当に本人なのか、複製体なのか、T計画由来なのかはVersion 0.9.0では断定しない
- 二刀流
- 古い和装と終末世界で補修した装備を組み合わせる

通常攻撃：

- 二刀による連続斬り
- 単体と大型敵への高い継続damage
- 撃破後に次の敵へ踏み込む
- TKYより技量、受け流し、対強敵を重視する
- 遠距離攻撃と大群に明確な弱点を残す

手動アビリティ：**二天一流・無空**

- 数秒間の受け流し構えへ入る
- 次に受ける近接攻撃または明確に予告されたboss攻撃を受け流す
- 直後に二刀の交差斬りで反撃する
- bossへ高い弱点damageと短い怯みを与える
- 構え中に攻撃されなかった場合は、前方の有効targetへ踏み込み斬りを行う
- 予告のない遠距離攻撃まで万能に無効化しない

icon motif：二本の刀と中心が空いた円。

### 3.5 マヨちゃん

人物：

- チワワ
- 性別不詳
- クマバーソン、その妻、子どもが家族で飼っている犬
- かわいらしいタクティカルハーネスを着用
- 過去に感染体へ噛まれたが感染を乗り越えた
- 癒しキャラとしての可愛さと、戦闘時の異常な凶暴性を両立する

通常攻撃：

- 高速で敵へ接近し足元へ噛みつく
- 小型・高速敵を優先する
- 噛みついた敵の移動を短時間低下させる
- 巨大bossへ正面固定せず、側面を狙う
- 実寸のまま豆粒化させず、ハーネス、発光marker、outline、動きの誇張で視認性を確保する

手動アビリティ：**凶暴マヨ**

- 移動速度、攻撃速度、target変更速度を上昇させる
- 敵から敵へ猛進して連続攻撃する
- 発動中はHPが継続的に減少する
- アビリティのHP減少だけで0にならず、安全下限へ達した時点で強制終了・退避する
- 終了後は長い再出撃待ちを持つ

戦闘不能・退避：

- マヨちゃんへ通常の味方死亡、corpse、感染、zombie化、焼却処理を適用しない
- 戦闘不能時は、短い倒れ込み、チワワの負傷voice、起き上がり、移動拠点への逃走を一連の専用animationにする
- player-facing表示は`マヨちゃん退避`または`負傷退避`とする
- 死体を残さない
- 血まみれの死亡演出を使わない
- 再出撃cooldown後に再配置可能にする

icon motif：可愛いチワワの顔と赤い速度・凶暴化accent。過度に恐ろしい犬顔へ変えない。

## 4. 既存11ユニットの手動アビリティ

既存の武器、role、target priority、個性を壊さず、一押しで用途が理解できる能力にする。全能力は個体ごとに独立cooldownを持つ。

### 4.1 パイセン — 気合連打

- 前方の最寄り敵へ短く踏み込む
- 素早い連続拳打を行い、最終打で周囲を押し戻す
- targetがいない場合はready iconを出さない
- icon motif：握り拳と複数のimpact line

### 4.2 ハチ — 疾駆迎撃

- 射程内の走行型、高速型、後方へ抜けようとする敵を優先する
- targetへ高速接近し、バールの強打で短く怯ませる
- 高速敵がいない場合は、最も近い有効targetを選ぶ
- icon motif：鉤形バールとspeed line

### 4.3 ミズチ — 精密排除

- 射程内の遠距離敵、特殊個体、高危険targetを優先する
- 一度構えて高威力・高貫通の精密射撃を行う
- 該当targetがいない場合は、射程内で最もHPの高い敵を選ぶ
- icon motif：長銃身と一点reticle

### 4.4 ナオ — 緊急処置

- 射程内でHP割合が最も低い生存味方を自動選択する
- 大きく回復し、解除可能な移動低下等を一つ解除する
- 短時間のdamage軽減を付与する
- corpseを復活させる能力にはしない
- 負傷味方がいない場合はready iconを出さない
- icon motif：救急cross、包帯、保護ring

### 4.5 タタラ — 地砕衝

- 大型ハンマーを地面へ叩きつける
- 前方と周囲へ範囲damage、怯み、短いarmor低下を与える
- 感染拠点・構造物にも有効だが、通常攻撃の役割を消すほど過剰にしない
- icon motif：hammerと割れた地面

### 4.6 クレイジーキング — 狂王暴走

- chain sawをoverdriveし、短時間前方の密集群へ突入する
- attack速度、移動速度、円形範囲damageを上昇させる
- 発動中は押し返されにくくする
- 無敵にはせず、高riskな前線投入という性格を維持する
- icon motif：回転するchain saw teethと王冠形のarc

### 4.7 クマバーソン — 鉄鍋仁王立ち

- 周囲の敵を挑発して自分へ向ける
- 一定時間damage軽減と緩やかな自己回復を得る
- 背後の味方を守り、前線を止める役割を強調する
- icon motif：正面を向いたfrying panと防御wave

### 4.8 ババヤガ — 弱点査定

- 射程内の特殊個体、boss、高危険targetを自動選択する
- 精密射撃を一発行い、一定時間targetの被damageを増加させるmarkを付ける
- 証券・分析に長けた人物像と弱点看破を接続する
- icon motif：pistol reticle、analysis line、下向きdefense marker

### 4.9 レイダー — 制圧掃射

- その場で構え、前方の直線上へ軽機関銃を連続掃射する
- 複数targetを貫き、命中した敵の進行を抑える
- 発動中の射線とdamage対象を一致させる
- icon motif：LMG muzzleと直線上の複数impact

### 4.10 ガンテツ — 鉄壁展開

- 大型盾を地面へ固定する
- 前方の敵を挑発し、自身の正面防御と背後味方へのdamage軽減を強化する
- 発動中は移動しない
- 盾を通過する攻撃と防げない攻撃を視覚的に区別する
- icon motif：地面へ固定された大型shieldと左右の防護chevron

### 4.11 モンキー — 即席捕縛罠

- 高速敵または敵密集経路を自動選択する
- 地面へ即席trapを設置し、範囲内の敵を短く拘束した後にslow化する
- 既存のtrap・妨害・足止め役を強調する
- icon motif：spring trap、cable、足止めmarker

## 5. Ability icon制作基準

- 全16能力へ専用iconを1種類ずつ制作する
- 約24〜32pxのvisible表示でも、主要silhouetteを判別できること
- tap領域はvisible表示より広く取る
- iconは原則1〜2個の主要shapeで構成し、細部を詰め込みすぎない
- ability名の文字をicon内へ押し込まない
- ready時だけ表示するため、cooldown数字・ringをicon assetへ描き込まない
- 全iconを同じframe、edge weight、lighting、汚れ、軍事端末UIへ統一する
- character固有色はaccentとして使い、色だけを識別手段にしない
- pink〜magentaはTKYの`光刃解放`を優先識別色とする
- マヨちゃんは可愛さを失わず、他iconと同じ戦闘UI品質を持たせる
- icon galleryを844×390・844×340で確認し、潰れ、誤認、類似、背景同化を0件にする

## 6. 実装・Save

- fighter instanceごとにmanual abilityのcooldown、active、used、target、animation stateを持たせる
- saveへ戦闘中の個体cooldownを恒久保存しない。ただしsurvival checkpoint再開で必要なrun stateは二重発動・無料再使用が起きない形で保存する
- pause、2倍速、tab非表示、復帰、戦闘終了、再戦でcooldownが二重進行しない
- unit死亡・退避・除去後に、孤立したready icon、hit target、timerを残さない
-同一個体の一回のtapでability damage、heal、status、SE、VFXを二重発火させない
- 既存11体の通常攻撃、AI、target priority、既存voice、weapon soundを削除せず、manual abilityを追加する

## 7. 必須QA

- 全16unitでready → tap → 発動 → icon消失 → cooldown終了 → icon再表示が成立
- 同じunitを2体以上出撃し、各個体が独立して発動可能
- 一方の個体が使用しても、readyな別個体のiconとabilityを消さない
- 大量出撃時のicon overlap、safe area、HUD干渉、誤タップ0
- target不在、負傷者不在等でno-op buttonを表示しない
- 1倍・2倍、pause、tab復帰、再読込で二重発動0
- 1280×720、844×390、844×340、Chromium、WebKit iPhone相当
- 新5体の専用animation、VFX、SE、voice、weapon描画を確認
- マヨちゃんがcorpse、感染、zombie化、焼却状態へ遷移しない
- independent read-only reviewでHigh／Medium未解消0

## 8. 非対象

- 頭上へ常時表示するcooldown timer・ring
- unit kind全体で共有するmanual ability cooldown
- ready iconを一個のclusterへまとめる操作
- 二段階の地面target指定を全unitへ強制すること
- 敵・bossの頭上manual ability button
- online操作、PvP用ability同期
- 新しい別battle engine
