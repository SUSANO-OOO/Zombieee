# Combat VFX sources

Runtime selection: rubberduck, “25 special effects rendered with blender”, CC0 1.0.
https://opengameart.org/content/25-special-effects-rendered-with-blender
Selected original 30-frame fire+smoke explosion sequence; its Blender source and compositing workflow are included in the original archive.

Ground dust and aftermath: Kenney, “Smoke Particles”, CC0 1.0.
https://kenney.nl/assets/smoke-particles
Original license is preserved in kenney-smoke/license.txt.

Runtime atlas builder: scripts/build-v100-combat-vfx.mjs. Original alpha, source hashes, encoding and runtime paths are recorded in runtime-provenance.json.
These are credited third-party source images; game timing and compositing are our implementation.

Unadopted evaluations: Sinestesia cartoon explosions, generated VFX sheets with an opaque checkerboard, and fscopel's Photo Realistic Explosions. They are not included in the runtime manifest or shipped as accepted art.
