## Production method

The selected files are project-original AI-assisted illustrations directed and selected for Zombieee. They are stored as nonruntime authoring masters so that Luna can make optimized, traceable runtime derivatives without inventing identity.

Segawa was generated using Producer-provided private face photographs as local visual reference. Those photographs remain outside the repository and must never be copied into Git, build output, QA artifact, or release media. The committed master is an illustrated derivative, not a source photograph.

The mutated Mugarian president r4 was generated from the approved human-president identity direction and then cleaned to true RGBA transparency. The earlier two-arm r3 remains an unselected local candidate. The selected r4 has exactly four arms/four hands with coherent shoulder ownership.

TAKUYA-Ω r2 incorporates the latest Producer correction: no orange clothing, stitched/scarred horror, an oversized sword/maul, and TAKUYA identity continuity. It was cleaned to true RGBA transparency; visible checkerboard pixels are not an alpha substitute.

The shared minor-human event silhouette is licensed only inside this project for minor human speakers without identity masters. The Producer selected r2 as a simple featureless, gender-neutral and age-neutral silhouette. It carries no face, hair, costume, occupation, accessory, weapon, ethnicity, or named-person identity cues and does not confer approval to replace named characters. The earlier r1 identifiable-person portrait is rejected and excluded from the selected file list.

## Nonselection rule

Files with rejected/superseded revisions are not deleted from a local artist workspace solely to make a clean report. They are excluded from the Git index and may not be referenced by runtime code. Selection is proven by this finite path/hash list, not by assuming every nearby file is approved.
